# 策略 02：固定种子全收集逃脱（full-clear-escape）

## 这个策略满足什么

**游戏目标**：Backrooms — Level 0 的完整胜利线——**固定一粒种子，收齐全部 8 张
日记页、喝光全部 4 瓶杏仁水，推开出口门走进亮光，游戏结算 `state=won`（YOU GOT OUT）**。
这要求同时解三道题：

1. **全图知识**：8 张页、4 瓶水、出口门、实体出生点全部由种子决定且观测里故意
   不给坐标——必须拿种子在游戏外逐位重建生成算法（本策略的 `bot/levelgen.py`
   把上游 `level.ts` 移植到了第 9 步：比策略 01 多出杏仁水、出口门、实体出生格）；
2. **实体生存**：首页收下后游荡者立即苏醒（或开局 45 秒到点自动醒），全程游荡
   /跟踪/追逐/搜索四种状态，贴身 1.3m 即死；
3. **三种交互**：取页（`[E] TAKE PAGE`）、喝水（`[E] DRINK ALMOND WATER`，
   瓶子在地上，要俯身瞄准）、开门（`[E] PUSH THE DOOR`，8 页齐了才出现）。

**策略定义**（bot/fullclear.py 的行为，每一条都是代码里的具体规则）：

| # | 决策点 | 规则 |
|---|--------|------|
| 1 | 随机性 | 每局 `reset(seed=N)` 固定种子（默认 1234），迷宫/8 页/4 水/出口门/实体位置全由它决定 |
| 2 | 地图知识 | 同种子离线重建迷宫（页/水/门/实体出生格），出生点与观测对不上（>0.25m）立即报错 |
| 3 | 巡回 | **贪心近邻**：从当前位置对每个未收物资算 BFS 走路距离，取最近者；取完一个再算下一个（12 个物资点 + 出口，鲁棒于绕路） |
| 4 | 避敌选点 | 1 级威胁（实体 15~24m 内）继续巡回，但剔除「朝实体方向」的物资——候选物资的实体 BFS 距离必须不小于自己当前位置的 |
| 5 | 威胁分级 | chase <40m、stalk <24m、roam <15m、search <16m、任意状态 <10m → 立即规避；1 级 + 连续 3 周期逼近 ≥1m 也升级 |
| 6 | 规避选点 | ① 被它看见 → 12 步内找**无视线**的拐角格（实体 BFS ≥6，先断视线）；② 已不被看见 → 18 步内找实体 BFS 最远的格子拉远；两档都要求离自己 ≥2 格、边界环格减分（死角会它一堵就没路） |
| 7 | 冲刺纪律 | chase/stalk <32m 或任意 <7m → 按住 Shift 冲刺（4.7 > chase 4.55 > stalk 2.15）；体力 <0.10 自动放弃防跛行；规避中**不停车转身**（边走边转，停车=送死） |
| 8 | 规避解除 | 按状态分档：**stalk 必须推过 38m**（它的放弃线是 36m，推不过就是永久缠斗）；roam/search 26m；chase 只能等它自己失明 3.5s 后放弃；单次规避 150s 强制返回防对峙 |
| 9 | 取页 | 站到页法线方向 1.35m，横纵瞄准页面，`[E] TAKE PAGE` 出现按 `e`；页数没涨就重新瞄准再试，8 次失败弃页换目标 |
| 10 | 喝水 | 站到「瓶底→格心」方向退 1.35m（同格直线必不穿墙），**俯身瞄准瓶底**（组原点在地上），`[E] DRINK ALMOND WATER` 出现按 `e`；喝掉的判据=提示消失+体力回满 |
| 11 | 开门 | 走到 `door_pos + 朝内 1.2m` 一次站定，**独立瞄准循环**（不再走路，避免视角被行走修正打掉），`[E] PUSH THE DOOR` 出现按 `e` → `exit_open` |
| 12 | 逃脱 | 门开后直冲门位——玩家与门 XZ 距离 <1.05m 游戏即判 `won`；除非 chase 贴脸且离门 >15m，否则不减速 |
| 13 | 终局 | `state=won` → 收录（结算画面多留 2 秒进录像），bot_log/summary 写进录制目录；任何失败路径同样完整留档 |

**与策略 01 的关系**：01 是它的前两块积木（迷宫移植到第 8 步 + 取页交互），
01 的失败局（`--pages 2` 被实体击杀）正是本策略实体规避的校准起点。

## 本文件夹的产物

| 路径 | 内容 |
|---|---|
| `bot/levelgen.py` | 迷宫生成逐位移植（到第 9 步：页/涂鸦/水/假出口/实体出生/出口门），`python3 levelgen.py` 可离线自测（含 seed=777 实体出生格地面真值核对） |
| `bot/fullclear.py` | 内挂本体：二维鼠标代数、贪心巡回、威胁分级与规避、取页/喝水/开门三交互、逃脱编排 |
| `recordings/backrooms/<id>/` | 一局一目录（video.mp4 / state.jsonl / input.jsonl / frames.jsonl / audio.wav / meta.json / bot_log.jsonl / summary.json） |
| `logs/<run>.log` | 每次运行的控制台全文 |

## 怎么跑

```bash
../../run.sh                                    # 默认就是本策略，seed=1234
../../run.sh --seed 777                         # 换一粒种子换一张迷宫（出生格/页/水/门/实体全变）
../../run.sh --max-seconds 1200                 # 放宽墙钟预算（默认 900s，实测 662s 用满全程）
```

注意：游戏本体的装饰性随机（灯光爆闪时机、实体追逐抖动、瓶身朝向）每次不同
（SCOPE.md 明文记录），所以**不同局的实体行为轨迹会不同**——策略靠实时观测+
规避应对，不靠预测实体走位；迷宫与物资点位则同种子必然一致。
