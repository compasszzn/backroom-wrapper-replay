# 策略 01：固定种子找一页纸（grab-one-page）

## 这个策略满足什么

**游戏目标**：Backrooms — Level 0 的入门目标——在程序化迷宫里**找到一张钉在墙上的
日记页**就算达成（8 张页全收才会开出口门，本策略不涉及）。

**策略定义**（bot/pagefinder.py 的行为，每一条都是代码里的具体规则）：

| # | 决策点 | 规则 |
|---|--------|------|
| 1 | 随机性 | 每局 `reset(seed=N)` 固定种子（默认 1234）——迷宫、8 张页、4 瓶水、出口门、实体位置全部由种子决定 |
| 2 | 地图知识 | 拿同一粒种子在游戏外逐位重建迷宫（bot/levelgen.py，对照上游 level.ts 移植到第 8 步 pageSpots），**提前知道每张页钉在哪面墙上**；出生点与观测对不上（>0.25m）立即报错，绝不带错图导航 |
| 3 | 选页 | 从当前位置对每张未取页算 BFS 走路距离，取「走路易达 + 近」最小者 |
| 4 | 走路 | A* 出格心路径后**拉直**（取直线可走的最远路径点，余量 0.34m），每 ~300ms 观测→修正视角→按 `w` 前进；偏航 >31° 先停下原地转身 |
| 5 | 取页 | 站到页法线方向退 1.35m 处，瞄准页位，等 `[E] TAKE PAGE` 提示出现按 `e`；按完页数不变就重新瞄准再试，6 次都失败则放弃该页换下一张（连续 3 张失败判地图重建有误） |
| 6 | 卡住自救 | 2.5 秒挪不动 → 倒退 0.4s + 侧转 90° + 前进 0.7s，重规划 |
| 7 | 终止 | 拿到目标页数（默认 1 张）即成功收工；对实体**零规避**（拿到第 1 张页时实体苏醒，正好收工——本策略不与实体长期共处） |

**「内挂」**：bot 走 harness 的 numeric 信道读结构化状态（位置/朝向/页数/提示/实体），
输入仍走 wrapper 标准键鼠通道，因此 `input.jsonl` 是完整有效的输入序列。

## 验证过的结论

- seed=1234 / seed=777 出生点重建误差 0.0m，页位经实际取页验证（5 局成功）。
- `--pages 2` 的尝试（seed=777，20260918-130616）证明**本策略不可扩展到多页**：
  实体在第 1 张页后苏醒，bot 无规避逻辑，被 stalk 从 14.6m 贴近、chase 3 秒内击杀
  （bot_log.jsonl 里有完整决策现场）。多页 + 逃脱需求由策略 02 接管。

## 本文件夹的产物

| 路径 | 内容 |
|---|---|
| `bot/levelgen.py` | 迷宫生成逐位移植（mulberry32/递归分割/页位），含 A* 与直线可走性检查 |
| `bot/pagefinder.py` | 内挂本体：观测拆包、鼠标像素代数、反馈式走路、取页、录制生命周期 |
| `recordings/backrooms/<id>/` | 本策略的历史录制（一局一目录：video.mp4 / state.jsonl / input.jsonl / frames.jsonl / audio.wav / meta.json / bot_log.jsonl / summary.json） |
| `logs/<run>.log` | 每次运行的控制台全文，与录制目录 summary.json 里的 `run` 字段一一对应 |

## 怎么跑

```bash
../../run.sh --strategy 01-grab-one-page            # seed=1234，找 1 页
../../run.sh --strategy 01-grab-one-page --seed 777 # 换种子换迷宫
../../run.sh --strategy 01-grab-one-page --pages 3  # 多收几张（会被实体追，非本策略目标）
```
